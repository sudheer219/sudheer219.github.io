Legacy migration — 8 applications, Angular 8 → 17/19

3-person team
≈ 7–8 months total
Situation

8 retail/supply-chain applications had been on Angular 8, falling behind on tooling and performance.

Challenge

Third-party packages hadn't kept pace with Angular's release cycle — mismatches and deprecated APIs across all 8 apps.

Action

Migrated each app — directly or incrementally depending on complexity — evaluating replacement libraries and manually testing UI flows after each jump.

Result

All 8 applications migrated with zero production incidents.

New build — Angular 21, from scratch

Individual contribution
Situation

A new application, built fresh rather than migrated — room to adopt Angular's latest patterns from day one.

Challenge

NX workspace and Angular Signals were both new to me — different mental model from the old file structure and RxJS-subscribe patterns.

Action

Structured the project around NX's domain-based workspace layout, and used Signals for reactive state instead of manual subscriptions.

Result

A cleaner, more maintainable project structure — and hands-on fluency in two patterns I didn't have before.
